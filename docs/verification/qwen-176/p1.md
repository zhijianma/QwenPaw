## 状态、请求与行为契约

公共组件不接收业务值、Agent、endpoint 或保存回调。模板更新没有新增
业务请求、写请求或轮询。浏览器按相同路由记录改前/改后 API 方法和路径：
Heartbeat、Agent Config、Voice、Environments、Token Usage、Debug、
Backups、Import 完全相同；Security 在延长到 8 秒、两边均完成加载后完全
相同；Models 改后请求为改前集合的子集，未新增请求。完整原始记录位于
本批证据包 `browser-verification.json`。

保持的关键语义：

- Heartbeat 仍按已加载 Agent 归属校验并调度原 `useAutoSave`。
- Agent Config 的 `RuntimeWorkbench` 仍等待原 `flushSave`；Security
  仍按当前 Tab 调用原保存处理器后切换，两者没有被统一。
- Voice 仍由原 hook 发出多项设置请求；Models 默认模型局部失败仍保留
  providers 与 warning。
- Environments 新建仍显式创建，既有变量仍自动保存并走原关闭处理。
- Backups 取消、先备份和恢复推进仍由 `useRestoreFlow` 控制；Import
  保留目标 Agent、取消及失败重试。
