## 状态、请求与行为契约

本批只组合页面结构，没有修改 API、字段、权限、请求参数、保存或关闭
处理器。新增契约断言覆盖：Community 只在提交时连接一次；Offload 保持
原调度次数和策略值；反馈变化不卸载编辑器；语言标签仍关联原控件；导航
排序使用稳定 ID，拖拽按钮保留键盘 sortable 语义。

PluginManager 将市场页头构造提取为共享 hook，独立市场页与设置页仍使用
相同分区路径和 target 参数。GeneralSettings 是唯一页级容器，嵌入的
NavigationSettings 只提供具名分区，避免嵌套页头。
